# 升级脚本说明

本目录包含所有版本升级脚本。每个升级脚本负责将系统从一个版本升级到下一个版本。

## 升级脚本命名规则

升级脚本命名格式：`upgrade-v{from_version}-to-v{to_version}.js`

例如：
- `upgrade-v1.0.0-to-v1.0.1.js` - 从 v1.0.0 升级到 v1.0.1
- `upgrade-v1.0.1-to-v1.1.0.js` - 从 v1.0.1 升级到 v1.1.0

## 升级脚本结构

每个升级脚本应包含：

1. **版本信息**：明确标识升级的源版本和目标版本
2. **升级步骤**：按顺序执行的升级操作
3. **回滚支持**：如果可能，提供回滚功能
4. **错误处理**：完善的错误处理和日志记录

## 运行升级脚本

```bash
# 运行特定版本的升级脚本
node upgrades/upgrade-v1.0.0-to-v1.0.1.js

# 或使用 npm 脚本
npm run upgrade
```

## 注意事项

1. **备份数据**：升级前请务必备份数据库和重要文件
2. **测试环境**：建议先在测试环境验证升级脚本
3. **版本检查**：升级脚本会自动检查当前版本，确保升级路径正确
4. **停止服务**：升级前请停止系统服务
5. **查看日志**：升级过程中注意查看日志输出
